# 🧵 FilamentMonitor

Єдина система моніторингу цін на 3D-філамент в Україні, обліку домашнього складу котушок та розрахунку витрат на 3D-друк.

---

## 🚀 Швидкий запуск

### Варіант 1: Через batch-файл (в 1 клік)
Двічі клікніть по файлу `run.bat` у папці проекту.

### Варіант 2: Через PowerShell
```powershell
.\run.ps1
```

### Варіант 3: Ручний запуск через віртуальне середовище
```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```
Після запуску відкриється веб-інтерфейс за адресою: [http://localhost:8501](http://localhost:8501)

## 📋 Основні можливості

### Вкладка 1: «Моніторинг цін у магазинах»
* **Парсинг 10 українських магазинів:**
  1. LBL Corp (`lbl-corp.com`)
  2. Filament Market (`filament.org.ua`)
  3. Daniparts (`daniparts.com`)
  4. UKR3D (`ukr3d.com.ua`)
  5. 3D Smart (`3d-smart.com.ua`)
  6. MonoFilament (`monofilament.com.ua`)
  7. Plexiwire (`shop.plexiwire.com.ua`)
  8. Epic3D (`epic3d.com.ua`)
  9. 3D Plast (`3dplast.biz`)
  10. Pochatok (`pochatok.ua`)
* **Автоматичне очищення URL:** відсікання UTM-міток, fbclid тощо при додаванні нових категорій/товарів вручну.
* **Жорстка фільтрація ваги:** автоматичне ігнорування бобін > 1.1 кг (2 кг, 2.5 кг, 3 кг, 5 кг), врахування лише стандартних намоток (0.5 кг, 0.75 кг, 0.85 кг, 1 кг).
* **Авто-розрахунок:** колонка «Ціна за 1 кг (грн)» та «Ціна за 1 г (грн)».
* **Фільтри:** тип пластику (PETG, TPU / Flex / Elastan, PLA, ABS / ASA, CoPE, Nylon, PCTG), твердість TPU (95A, 90A, 85A, 40D), колір, магазин, перемикач «Тільки в наявності».
* **Швидке додавання:** кнопка `+ Склад` напроти кожної позиції переносить котушку в інвентар в один клік.

### Вкладка 2: «Мій склад філаменту (Інвентар)»
* **Візуальні картки котушок** з прогрес-баром залишку у грамах та відсотках.
* **Додавання котушки вручну** (бренд, магазин, тип пластику, колір, твердість TPU, початкова вага, ціна покупки, тара за замовчуванням 200 г).
* **Швидка інвентаризація на вагах:** кнопка «⚖️ Зважити», введення ваги брутто (з кухонних ваг) — програма сама віднімає тару та оновлює чистий залишок.
* **Алерти залишку:** якщо залишок < 150 г — жовтий статус з кнопкою «🔍 Перевірити ціни на цей пластик»; < 50 г — критичний червоний статус.
* **Статуси котушок:** «В роботі», «Запакована (нова)», «Закінчилася (архів)».

### Вкладка 3: «Журнал друку та списання пластику»
* **Швидке списання:** вибір котушки -> назва проєкту -> витрачено грамів -> розрахунок собівартості -> списання з котушки.
* **Імпорт .gcode / .3mf / .bgcode:** Drag-and-Drop файлу слайсера (OrcaSlicer, PrusaSlicer, Cura, Bambu Studio) з автоматичним зчитуванням грамів та розрахунком собівартості.
* **Облік браку:** чекбокс «Невдалий друк (брак)» для аналітики зіпсованого пластику.
* **Історія друків:** журнал з можливістю видалення запису (і повернення списаного філаменту назад на котушку).

### Вкладка 4: «Аналітика та витрати»
* **Загальний облік:** скільки кг пластику зараз є вдома та його сумарна вартість у гривнях.
* **Витрати за місяць та за весь час:** у грамах та гривнях.
* **Середня ціна 1 кг** купленого пластику за типами (PETG vs TPU vs PLA тощо).
* **Інтерактивні графіки (Plotly):** динаміка витрат по місяцях, кругова діаграма типів на складі, порівняння цін між магазинами, статистика браку.

## 🛠️ Стек технологій
- **Python 3.12**
- **Streamlit** (UI з вкладками, реактивними картками та модальними вікнами)
- **SQLite** (`data/filament.db` — повністю локальне автономне зберігання)
- **Playwright + BeautifulSoup4 + httpx** (парсинг динамічних та статичних сторінок)
- **Plotly** (інтерактивна аналітика та діаграми)
